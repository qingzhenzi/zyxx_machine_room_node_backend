# 跨房间排课 · 可视化原型

Room Node Console「课表」页的可交互静态原型，用于对比三种排课形态（周网格 / 资源时间轴 / 编排矩阵）。
完全自包含：`index.html + styles.css + app.js`，不依赖任何 CDN、外部字体或外链图片，可直接用
`file://` 打开（也可 `python3 -m http.server` 起静态服务）。

## 打开方式

直接双击 `index.html`，或用 hash 直达某个视图：

| hash | 说明 |
| --- | --- |
| `index.html#week` | A 周网格课表（周一–周日 × 5 个节次，跨房间汇总） |
| `index.html#timeline` | B 资源时间轴（单日，行=房间，横轴 08:00–21:00） |
| `index.html#matrix` | C 全房间编排矩阵（行=房间，列=周一–周日 × 5 节次，横向滚动） |
| `index.html#timeline/b05` | 直达时间轴并打开该课块的右侧详情抽屉（冲突态） |

## 交互清单

- 顶部分段控件切换三视图；hash 同步，可直接分享定位。
- 共享一套 mock 数据（34 个课块 / 2 区域 / 8 房间 / 8 门课），切换视图保留日期与筛选。
- A：区域 / 房间筛选、搜索（弱化不匹配课块）、冲突 chip 聚焦、周导航、格内 `+N` 折叠、底部课程色图例。
- B：课块拖拽（水平换时间 + 垂直换房间、吸附 10 分钟、非法落点红色预览并取消）、点击空白弹「新建课程」
  浮层（预填房间 + 时间）、点击课块开右侧抽屉、悬停出现拉伸把手（视觉）、复制到… / 删除。
- C：拖拽框选多格（半透明 accent 选区 + 底部「批量应用课程到 N 个时段 / 清除」操作条）、单元格点击新建草稿、
  「批量模式」开关、横向滚动查看周三–周日。
- 三视图冲突统一标注：红色 = 同房间重叠，琥珀色 = 同一教师重叠；`冲突 2` chip 可聚焦。
- 右上角「新建课程」弹出表单（课程 / 教师班级 / 房间 / 星期 / 节次 / 来源），提交后前端生效并 toast 提示。

## 说明

- 视觉 token 取自 `frontend/src/assets/main.css`（canvas / surface / line / ink / accent 等），
  控制台外壳（侧边栏 240px、顶栏、底部状态栏）按 `frontend/docs/screenshots/*.png` 复刻。
- 截图位于 `docs/design/prototype-{week,timeline,matrix,timeline-detail}.png`（1440×900）。
- 纯静态演示：所有增删改只发生在浏览器内存，刷新即恢复初始 mock 数据，不请求后端。
